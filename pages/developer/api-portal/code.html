Authentication Overview

The OmniPlatform API uses API keys to authenticate requests. You can view and manage your API keys in the Developer Dashboard.

info

Security Note

Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, and so forth.

API Key Management

All API requests must be made over HTTPS. Calls made over plain HTTP will fail. API requests without authentication will also fail.

Request Format

You provide your API key in the Authorization header using the Bearer scheme.

Authorization: Bearer YOUR_API_KEY
curl -X GET "https://api.omni.com/v1/user" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

const options = {
  hostname: 'api.omni.com',
  path: '/v1/user',
  method: 'GET',

  }
};

const req = https.request(options, (res) => { ... });
req.end();
